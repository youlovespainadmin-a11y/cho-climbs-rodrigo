🗺 Geoapify 지도 연결

복사한 Geoapify API 키를 아래에 붙여넣어 줘. Geoapify가 실패하면 OpenStreetMap/CARTO로 자동 전환해. 이 키는 서버로 전송하거나 HTML에 박아두지 않고 이 브라우저에만 저장해. 지도가 로드될 때 Geoapify에는 타일 요청이 전송돼.

기존 키를 사용해도 돼.

주의: 공개 웹사이트 배포 전에는 Geoapify 대시보드에서 허용 도메인 제한을 설정하는 게 좋아.

▶ Importar vídeos de Rodrigo

Importa hasta 30 vídeos de Patones y 30 de Cuenca directamente desde las listas públicas. Necesitas una YouTube Data API v3 key distinta de la clave Geoapify. La clave se guardará en el almacenamiento local de este navegador después de una importación correcta, para no tener que introducirla de nuevo. No compartas este archivo con la clave incluida ni uses una clave sin restricciones en una web pública. Los vídeos y miniaturas se guardan localmente.

Los títulos, grados y vídeos se cargarán a partir de YouTube. Las ubicaciones son agrupaciones aproximadas por zona.

Si no tienes una clave de YouTube, puedes explorar las tres fichas enlazadas y las dos listas oficiales que ya están incluidas.
